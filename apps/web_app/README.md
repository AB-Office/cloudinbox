# CloudInbox Web App

CloudInboxサービスのWebアプリケーション（Vue 3 + Vuetify）

## 技術スタック

- Vue 3 (Composition API)
- TypeScript
- Vite

## セットアップ

```bash
cd apps/web_app
npm install
```

## 開発サーバー起動

```bash
npm run dev
```

## ビルド

```bash
npm run build
```

## プロジェクト構造

```
apps/web_app/
├── src/
│   ├── main.ts          # エントリーポイント
│   └── App.vue          # ルートコンポーネント
├── vite.config.ts       # Vite設定
├── tsconfig.json        # TypeScript設定
└── package.json
```
