Gmailにまとめていた"あの便利さ"が、使えなくなります

これまでGmailでは、他のメールアカウントをPOPで取り込み、1つの受信箱で管理できました。

しかし、この機能は廃止されます。

  • 独自ドメインのメールをGmailで見ていた
  • 複数アカウントを行き来するのが面倒
  • PCブラウザでまとめて管理したい

→ これからは、代替手段が必要です。

複数のメールを、1つにまとめる

独自ドメイン、プロバイダメール、レンタルサーバーのメールなど、POP3対応メールをCloudInboxに集約できます。

  • アカウントを切り替えない
  • 見落としを防ぐ
  • 受信管理がシンプルに

メールは「暗号化」されて保存されます

CloudInboxでは、メール本文を暗号化した状態で保管します。第三者が内容を読むことはできません。

暗号化と「鍵管理」は別物です

CloudInboxでは、暗号を解く「鍵」をGoogle Cloudの専用サービスで管理しています。

Cloud KMS

暗号化の鍵を安全に保管・管理

  • 鍵のローテーション
  • アクセス制御
  • 監査ログ

Secret Manager

パスワードなどの機密情報を安全に保管

  • コードに直接保存しない
  • 必要な処理のみ参照可能

鍵やパスワードを、アプリやデータベースに直接保存することはありません。

[図: メール本文（暗号化） / 鍵（KMS） / 機密情報（Secret Manager）]
