# Product Overview

CloudInboxは、外部メールサーバ（POP3）から受信したメールをクラウド上へ保存し、スマートフォンアプリ（Flutter）からどの端末でも同じ受信箱を閲覧できる「クラウド受信箱サービス」です。

Googleの外部メール受信終了後、複数メールアカウントを一元管理できる代替サービスとして設計されています。

## Core Capabilities

1. **外部メール受信**: POP3プロトコルによる自動メール受信とクラウド保存
2. **統一受信箱**: 複数アカウントのメールを単一の受信トレイで閲覧
3. **容量管理**: プランベースのストレージ制限と使用量追跡
4. **クロスプラットフォーム**: Flutterアプリによるモバイル・Web対応

## Target Use Cases

- 複数のメールアカウント（POP3）を一元管理したいユーザー
- Googleの外部メール受信終了後の代替手段を探しているユーザー
- どの端末からでも同じ受信箱にアクセスしたいユーザー
- クラウド上にメールを安全に保存・管理したいユーザー

## Value Proposition

> 外部メールを、あなた専用のクラウド受信箱へ。

- **一元管理**: 複数アカウントのメールを単一の受信トレイで管理
- **クラウド保存**: Firebase Storageによる安全なメール保存
- **容量制御**: プランベースのストレージ管理（Freeプラン: 5GB）
- **自動受信**: 定期的な自動メール取得（15-30分間隔）
